# 针对大型文本与巨型数据的处理准则 (Large File Diagnostics Protocol)

**触发条件**：当要求统计、提取、聚合处理大型数据文件（包含数千行及以上的 `.log`、`.csv`、`.json` 或是类似 `leetcode_submissions.md` 的超长记录文档）的宏观统计信息与极值时。

**禁止行为**：
- 绝对禁止使用 `view_file`、`cat`、`head` 等工具试图对原文件进行“多轮次、连续翻页”的原始探索！大文件在上下文里的无限堆积会导致 Token 超限（产生 400 错误）。

**必须执行的操作规范**：
1. **立刻转化为“后端程序员”视角**。
2. **侦察数据结构**：如果需要，仅允许通过抽取少量片段（如正则抽取出头部、前 20 行等）观察文件规律。
3. **编写脚本**：强烈要求通过调用控制台命令，**编写并执行一段 Node.js 或 Python 自动化小脚本**。让脚本在后台负责加载整个大文件，完成数据清洗、过滤和聚合最值运算。
4. **简洁输出**：脚本必须只 `console.log` / `print` 出最精华的核心求余结果（比如前五名统计汇编）。
5. 最终只凭借读取脚本打在终端里总结结果来给用户反馈，拒绝盲目翻书！
